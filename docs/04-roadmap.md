## Этап 3. Пересмотреть дедупликацию

Правило «повторить через 7 дней» писалось под Reddit, где пост уходил из ленты сам. Скидка в Steam висит в выдаче всю распродажу, и правило будет повторять её каждую неделю.

- [ ] Решить политику повторов. Предложение: ключ это app id вместе с процентом скидки, повтор только при изменении скидки, запись удаляется, когда игра пропала из выдачи.
- [ ] Режим первого запуска: пометить все текущие скидки отправленными без публикации, чтобы не отправить два десятка сообщений разом.
- [ ] Ограничение числа сообщений за цикл, например 10, с переносом остатка на следующий цикл.
- [ ] Защита от одновременного запуска: файловая блокировка или `BEGIN IMMEDIATE` в SQLite.

## Открытые вопросы

| Вопрос | Варианты |
|---|---|
| Порог числа отзывов | 200 отсекает две игры со скидкой 90% и рейтингом 98%. 50 их пропустит |
| Исключать ли Casual | Уносит нормальные игры. Сейчас в рекомендованном запросе не исключается |
| Интервал проверки | 12 часов как сейчас или раз в сутки. Поиск Steam отдаёт все текущие скидки, пропусков не будет при любом варианте |
| Бесплатные раздачи | 12 сентября `specials=1` вместе с `maxprice=free` вернул ноль. Попадают ли туда временные раздачи со скидкой 100%, не проверено: в тот день их могло просто не быть |
| Куда отправлять | Сейчас личный чат. Для канала нужно добавить бота администратором и указать id канала |
