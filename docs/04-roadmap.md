## Этап 2. Перейти на поиск Steam

Цель: скидки берутся из магазина Steam, Reddit больше не используется. Справочник: [02-steam-search-api.md](02-steam-search-api.md).

- [x] Новый модуль источника с рекомендованным запросом и эталонным парсером из справочника: `steam_search.py`.
- [x] Регион, пороги и список исключаемых тегов вынести в конфиг: `STEAM_CC`, `MIN_DISCOUNT_PERCENT`, `MIN_REVIEW_PCT`, `MIN_REVIEWS`, `EXCLUDE_TAG_IDS`.
- [x] Обработка ответа 429 и не-JSON тела как временной ошибки, а не пустой выдачи. Временные ошибки повторяются один раз через минуту.
- [x] Проверка, что `total_count` попал в разумный диапазон. Защита от молча проигнорированного параметра. Диапазон ловит только сброс `specials` и пустой ответ. Проигнорированный `supportedlang` ловит контрольный запрос без фильтра языка раз в сутки и при изменении `total_count` в 1.6 раза. Сброс `specials` дополнительно ловится по строкам без скидки, смена разметки по числу строк и доле разобранных.
- [x] `html.unescape` для названий перед экранированием MarkdownV2.
- [x] В сообщение добавить цену со скидкой и рейтинг отзывов: теперь они есть.
- [x] Удалить из `scraper.py` загрузку Reddit. Файл удалён целиком, запасной источник не оставлен.

Готово, когда за один цикл делается один запрос к Steam и приходят только игры с русским языком, скидкой от порога и хорошими отзывами.

> **Отклонение.** Одна страница это только лучшие по отзывам ~4% скидок: 24 из 248 подходящих, см. раздел «Одна страница или несколько» в [02-steam-search-api.md](02-steam-search-api.md). Число страниц задаёт `STEAM_MAX_PAGES`. По умолчанию 1, как в плане.

## Этап 3. Пересмотреть дедупликацию

Правило «повторить через 7 дней» писалось под Reddit, где пост уходил из ленты сам. Скидка в Steam висит в выдаче всю распродажу, и правило будет повторять её каждую неделю.

- [x] Решить политику повторов. Ключ это app id вместе с процентом скидки, повтор при любом изменении процента. Запись удаляется, когда игры нет среди отобранных дольше `FORGET_AFTER_DAYS` дней, по умолчанию 3: защита от дублей при колебаниях на границе выдачи.
- [x] Режим первого запуска: пометить все текущие скидки отправленными без публикации, чтобы не отправить два десятка сообщений разом. В чат приходит одно сообщение о запуске. Так же обрабатывается смена настроек отбора.
- [x] Ограничение числа сообщений за цикл, например 10, с переносом остатка на следующий цикл: `MAX_MESSAGES_PER_CYCLE`.
- [x] Защита от одновременного запуска: `flock` на `<DATABASE_PATH>.lock`.

## Открытые вопросы

| Вопрос | Варианты |
|---|---|
| Порог числа отзывов | 200 отсекает две игры со скидкой 90% и рейтингом 98%. 50 их пропустит |
| Исключать ли Casual | Уносит нормальные игры. Сейчас в рекомендованном запросе не исключается |
| Интервал проверки | 12 часов как сейчас или раз в сутки: `CHECK_INTERVAL_HOURS`. Пропусков нет при любом варианте, если `STEAM_MAX_PAGES` покрывает все подходящие скидки |
| Сколько страниц загружать | 1 страница даёт 24 скидки из 248 подходящих и фактический порог отзывов ~92%. 10 страниц покрывают все при текущих порогах, цикл длится около двух минут, уведомлений больше |
| Бесплатные раздачи | 12 сентября `specials=1` вместе с `maxprice=free` вернул ноль. Попадают ли туда временные раздачи со скидкой 100%, не проверено: в тот день их могло просто не быть |
| Куда отправлять | Сейчас личный чат. Для канала нужно добавить бота администратором и указать id канала |
