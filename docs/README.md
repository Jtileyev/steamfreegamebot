## Коротко

- **Что есть сейчас.** Бот раз в 12 часов читает RSS сабреддита r/steamdeals, вытаскивает процент скидки регулярками из заголовков постов и шлёт скидки от 70% в личный чат Telegram. Состояние хранится в SQLite.
- **Код рабочий, развёртывание нет.** Последний реальный запуск был 15 февраля 2026 года. systemd-юнит ссылается на несуществующие venv и пользователя.
- **Источник меняем на Steam.** Поиск магазина отдаёт авторитетные скидки, рейтинг отзывов и фильтр по русской локализации одним запросом. Подробности в [02-steam-search-api.md](02-steam-search-api.md).
- **Хостинг: отдельный VPS.** Бесплатный Vercel не позволяет запуск по расписанию чаще раза в сутки и не хранит файлы между запусками. Подробности в [03-hosting.md](03-hosting.md).
