## Коротко

- **Что есть сейчас.** Бот раз в 12 часов загружает поиск магазина Steam, отбирает игры с русским языком, скидкой от 70% и хорошими отзывами и шлёт новые и изменившиеся скидки в Telegram. Состояние хранится в SQLite. Код Reddit-версии удалён, план из [04-roadmap.md](04-roadmap.md) выполнен в коде.
- **Сколько скидок видит бот.** Одна страница поиска это лучшие по отзывам ~4% скидок: 24 из 248 подходящих на 12 сентября. Число страниц задаёт `STEAM_MAX_PAGES`, подробности в [02-steam-search-api.md](02-steam-search-api.md#одна-страница-или-несколько).
- **Надёжность.** Первый запуск и смена настроек отбора не рассылают старые скидки. Сбой Steam, смена разметки или проигнорированный фильтр дают ошибку цикла, а не тихий день. Если успешных циклов нет сутки, в Telegram приходит предупреждение.
- **Хостинг: отдельный VPS.** Бесплатный Vercel не позволяет запуск по расписанию чаще раза в сутки и не хранит файлы между запусками. Юнит systemd лежит в репозитории, развёртывание описано в [03-hosting.md](03-hosting.md).
