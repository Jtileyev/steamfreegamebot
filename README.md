# Steam Deals Bot 🎮

Telegram-бот, который присылает крупные скидки на игры в Steam с поддержкой русского языка и хорошими отзывами.

Источник данных это поиск магазина Steam. Устройство эндпоинта, фильтры и ловушки описаны в [docs/02-steam-search-api.md](docs/02-steam-search-api.md). История проекта, аудит старой версии и план работ лежат в [docs/](docs/README.md).

## Как работает

Раз в `CHECK_INTERVAL_HOURS` часов (по умолчанию 12) бот делает один цикл:

1. **Запрос к Steam.** `STEAM_MAX_PAGES` страниц поиска магазина по 100 строк с паузой 12 секунд. В выдачу попадают игры со скидкой и русским языком, без free-to-play и без тегов из `EXCLUDE_TAG_IDS`, лучшие отзывы первыми. Регион задаёт `STEAM_CC`. Одна страница это только лучшие по отзывам ~4% скидок, подробности в [docs/02-steam-search-api.md](docs/02-steam-search-api.md#одна-страница-или-несколько).
2. **Отбор.** Остаются игры со скидкой от `MIN_DISCOUNT_PERCENT`, от `MIN_REVIEW_PCT` процентов положительных отзывов и от `MIN_REVIEWS` отзывов. Пакеты и игры без отзывов отбрасываются.
3. **Сравнение с базой.** Уведомление уходит, если игры нет среди известных или изменился процент скидки. Скидка, которая висит в выдаче всю распродажу, приходит один раз.
4. **Отправка.** Не больше `MAX_MESSAGES_PER_CYCLE` сообщений за цикл, лучшие скидки первыми. Остальные уходят в следующих циклах.
5. **Чистка.** Игра, которой нет среди отобранных дольше `FORGET_AFTER_DAYS` дней, забывается. Если скидка вернётся, уведомление придёт снова.

**Первый запуск** на пустой базе ничего не рассылает. Текущие скидки помечаются известными, в чат приходит одно сообщение о запуске. **Смена настроек отбора** (`STEAM_CC`, `STEAM_MAX_PAGES`, пороги, `EXCLUDE_TAG_IDS`) работает так же: скидки, которые стали подходящими из-за новых настроек, помечаются известными без отправки. Поэтому настройки лучше выбрать до первого запуска, проверив их через `--dry-run`.

**Ошибки источника** не выглядят как тихий день. Цикл завершается ошибкой без отправки, если:

- Steam ответил 429, 5xx или не-JSON, в том числе после повтора через минуту;
- `total_count` вне диапазона `STEAM_TOTAL_COUNT_MIN..STEAM_TOTAL_COUNT_MAX`;
- строк на странице меньше, чем обещает её `total_count`, или разобрано меньше 90% строк с отзывами: Steam урезал страницу или поменялась разметка;
- больше половины игр в выдаче без скидки: Steam проигнорировал `specials`;
- контрольный запрос без фильтра языка вернул почти столько же игр: Steam проигнорировал `supportedlang`. Контроль делается раз в сутки и когда `total_count` изменился в 1.6 раза в любую сторону;
- на следующей странице `total_count` изменился в 1.6 раза относительно первой или упал больше чем на страницу;
- больше половины игр страницы повторяют прошлые страницы: Steam проигнорировал `start`.

Если скидки закончились между запросами и страница вышла короче, это не ошибка.

Сбой любой страницы это сбой всего цикла: по неполной выдаче скидки не забываются.

**Heartbeat.** Если успешного цикла не было `HEARTBEAT_HOURS` часов, в чат приходит предупреждение с последней ошибкой. Повтор не чаще раза в `HEARTBEAT_HOURS`, после восстановления приходит одно сообщение.

Каждый цикл заканчивается строкой итога в логе:

```
Итог цикла [ok]: разобрано 99 из выдачи 2525 (страниц 1), прошло фильтр 24, отправлено 2, уже известно 22, отложено 0, помечено без отправки 0, забыто 0, ошибок отправки 0, доставка неизвестна 0
```

Одновременный запуск двух циклов, например ручной `python bot.py` рядом с сервисом, блокируется файлом `<DATABASE_PATH>.lock`. Если запрос ушёл в Telegram, но ответ не получен целиком (таймаут, разрыв соединения, обрыв тела ответа), сообщение считается возможно доставленным: оно не повторяется, а остальные скидки цикла переносятся на следующий. Ошибка соединения или TLS-рукопожатия считается недоставкой, скидка будет отправлена в следующем цикле.

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | обязательна | Токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | обязательна | Личный чат, группа или канал. В канале бот должен быть администратором |
| `DATABASE_PATH` | `data/steam_bot.db` | Файл SQLite, путь от рабочей директории |
| `STEAM_CC` | `kz` | Регион магазина: валюта и ассортимент. Выберите один раз, база привязана к региону |
| `MIN_DISCOUNT_PERCENT` | `70` | Минимальная скидка, процентов |
| `MIN_REVIEW_PCT` | `80` | Минимум положительных отзывов, процентов |
| `MIN_REVIEWS` | `200` | Минимальное число отзывов |
| `EXCLUDE_TAG_IDS` | `3799,4085,12095,9130,6650` | Исключаемые теги: Visual Novel, Anime, Sexual Content, Hentai, Nudity. `none` отключает исключение |
| `STEAM_MAX_PAGES` | `1` | Страниц по 100 строк за цикл, до 30. При порогах по умолчанию все подходящие скидки помещаются в 10 страниц |
| `STEAM_TOTAL_COUNT_MIN` | `50` | Нижняя граница правдоподобного `total_count`. Сейчас около 2500 |
| `STEAM_TOTAL_COUNT_MAX` | `12000` | Верхняя граница. Без фильтра `specials` Steam отдаёт около 16 700 игр |
| `CHECK_INTERVAL_HOURS` | `12` | Интервал проверки |
| `MAX_MESSAGES_PER_CYCLE` | `10` | Лимит уведомлений за цикл |
| `FORGET_AFTER_DAYS` | `3` | Через сколько дней отсутствия скидка забывается. Должно быть дольше интервала проверки |
| `HEARTBEAT_HOURS` | `24` | Порог предупреждения об отсутствии успешных циклов |

Пустое значение переменной равносильно отсутствию. Неверные значения перечисляются при запуске, процесс завершается с кодом 1.

Словарь id тегов: `https://store.steampowered.com/tagdata/populartags/english`.

## Локальный запуск

```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt
cp .env.example .env    # заполнить токен и чат

venv/bin/python bot.py --dry-run   # что прошло фильтр, без Telegram и без записи в базу
venv/bin/python bot.py             # один цикл, код выхода 0 при успехе
venv/bin/python clock.py           # планировщик, как на сервере
```

Получить `TELEGRAM_CHAT_ID`: написать боту любое сообщение, открыть `https://api.telegram.org/bot<TOKEN>/getUpdates` и взять `"chat":{"id":...}`.

## Тесты

```bash
venv/bin/python -m unittest discover -s tests -t .
```

Тесты не ходят в сеть. Разбор проверяется на сохранённом ответе Steam из [tests/fixtures/](tests/fixtures/).

## Сервер

Бот работает на этой же машине из `/home/ubuntu/projects/steamfreegamebot` под systemd, юнит [steam-deals-bot.service](steam-deals-bot.service). Установка описана в [docs/03-hosting.md](docs/03-hosting.md). Обновление:

```bash
cd /home/ubuntu/projects/steamfreegamebot
git pull
venv/bin/pip install -r requirements.txt
venv/bin/python bot.py --dry-run
sudo systemctl restart steam-deals-bot
sudo journalctl -u steam-deals-bot -f
```

Ручной цикл запускайте от `ubuntu`, без `sudo`: `venv/bin/python bot.py`. Запуск через `sudo` создаст базу от root, и сервис не сможет в неё писать.

```

├── telegram_client.py     # Форматирование MarkdownV2 и отправка
├── database.py            # SQLite: известные скидки, meta, блокировка цикла
├── config.py              # Переменные окружения
├── logging_setup.py       # Логирование с вырезанием токена
├── steam-deals-bot.service
├── tests/
└── docs/
```
